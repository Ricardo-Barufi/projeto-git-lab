# 🚀 Projeto Git Lab

Laboratório prático de versionamento, fluxo Git, boas práticas e publicação com GitHub.

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 / JavaScript
- Git & GitHub
- Padrão Conventional Commits

## 📌 Histórico de Aprendizado
- [x] Configuração de identidade global (`user.name` e `user.email`)
- [x] Inicialização do repositório (`git init`)
- [x] Higiene de repositório com `.gitignore`
- [ ] Primeiro commit na branch principal (`main`)
- [ ] Criação e trabalho em branch de feature (`feature/...`)
- [ ] Integração de código (`git merge`)
- [ ] Publicação e sincronização remota (`git push`)
